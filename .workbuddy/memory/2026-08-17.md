## 08-19 16:41 U7_DEBUG 铁证 → ★最终根因：HAL v1.10+ 的 ChannelState[]（通道级状态）
- U7_DEBUG 抓包（COM4 hex→ASCII）：`MOVE done (ISR reached target)`（第一段 ISR 正常走完 100 步）+ `MOVE reject: START_IT FAIL`（第二段）→ **第二段 HAL_TIM_PWM_Start_IT 返回失败**，而此前已强制 `htim3.State=READY` → 说明检查的不是 State！
- ★根因：本工程 HAL 是 **v1.10+ 新版**，`HAL_TIM_PWM_Start_IT` 用 `TIM_CHANNEL_STATE_GET(ChannelState[])`（**通道级状态数组**）检查，不匹配返回 **HAL_ERROR**（非旧版 HAL_BUSY）。第一段 Start_IT 置 `ChannelState[CH2]=BUSY`，ISR 直接寄存器停 PWM 未还原 → 第二段必失败。**只改 htim->State 无效（新 HAL 中 State 是兼容遗留字段）**。

- ★★通用教训：**新 HAL(1.10+) 用 ChannelState[4] 通道级状态，Start_IT 返回 HAL_ERROR；ISR 直操寄存器启停 TIM 必须手动同步 ChannelState + State 两个字段**（旧固件走 HAL Stop_IT 所以正常）。
