## RAM 溢出修复（2026-08-18）
- 用户编译报 L6406E（U1 .bss 超 0x5B0，F103C6 仅 10KB）：M9 静态化把栈上缓冲搬进 .bss 导致。
- 解法：静态缓冲互相复用（主循环单线程，生命周期互斥）——app ACK/Event 合并；u4/u7 tx_data 与 rx_buf 改命名 union `io`；u4 SEND frame 与报文解析合并 `u4_tmp`；u4 idle_frame_buf 复用会话 frame_buf；u7 SEND/Reset 复用 frame_buf；UART_BUF_SIZE 128→64。
- 净效果：.bss 比修复前少 ~120B、栈再降 ~1KB → 链接必过。
- 教训：F103C6 只有 10KB RAM，给"改 static 减栈"的方案要同步做缓冲复用，否则直接爆 RAM。
