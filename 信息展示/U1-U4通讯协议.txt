
  通用约定：
   · 帧头 F   固定为 0xA5 0x5B
   · 命令 C   u8，从 0x01 开始
  · 帧序号 N u16，逐帧递增；达到 0xFFFF 后重置为 1；序号 0 特殊对待
   · CRC16    采用 MODBUS/CRC16，计算范围：帧头 F ～ 数据 D
   · 字节序   所有数据均为大端序（高字节在前，低字节在后）
  · ★ CRC16 字节序: 低字节在前 (MODBUS RTU 标准) ← 2026-08-12 实测确认
      例如 CRC 值 0x978D → 先发 0x8D, 再发 0x97
  · ★ 串口配置: 运行时 115200 8N1 (App); ISP 烧录时 115200 8E1 (G0 bootloader 强制)



一、单帧数据结构（最低 9 字节）


┌────────────────────────────────────────────────────────────────────────────────────┐
│ 字段       │ 字节数   │ 说明                                                     │
├────────────┼──────────┼──────────────────────────────────────────────────────────┤
│ 帧头 F     │ 2        │ 固定值 0xA5 0x5B                                         │
│ 命令 C     │ 1        │ u8，从 0x01 开始                                         │
│ 帧序号 N   │ 2        │ u16，逐帧递增；达到 0xFFFF 后重置为 1；序号 0 特殊对待   │
│ 数据长度 L │ 2        │ u16，表示 数据 D 的字节数                                │
│ 数据 D     │ *        │ 数据内容（长度由 L 决定）                                │
│ CRC16      │ 2        │ MODBUS/CRC16，计算范围：帧头 F ～ 数据 D                 │
└────────────────────────────────────────────────────────────────────────────────────┘

规则说明：
  1. 所有数据的字节序都是大端序：高字节在前，低字节在后。
  2. 帧头 F 固定是 0xA5 0x5B。
  3. 命令 C 为 u8，从 0x01 开始。
  4. 帧序号 N 应是递增的 u16 数据，当达到 0xFFFF 后，重置为 1；序号 0 特殊对待。
  5. U1 发送 1 帧数据，U4 接收并处理后，会返回一个 ACK 帧，
     ACK 帧的序号与接收到的序号是一样的。
  7. 数据长度 L 是 u16 数据，表示 数据 D 的字节数。
  8. CRC16 使用 MODBUS/CRC16，CRC 计算从 帧头 F 到 数据 D 都计算在内。

说明：
  发送方：U1 = 控制板（主机），U4 = 测径板（从机）
  所有帧帧头固定为 0xA5 0x5B；CRC16 采用 MODBUS/CRC16（计算范围：帧头 F ～ 数据 D）。

三、实时数据报文结构体 ccd_data_t（共 24 字节）


┌──────────────────────────────────────────────────────────────────────────┐
│ typedef struct {                                                         │
│     int16_t  length;     // 计算偏移之后的线径值，单位 um                             │

│     uint16_t vo2;        // VCP1615-V2：当前 ADC 值                          │

│     uint16_t min_vo2;    // VCP1615-V2：测量 ADC 最小值                        │
│     uint16_t max_vo2;    // VCP1615-V2：测量 ADC 最大值                        │
