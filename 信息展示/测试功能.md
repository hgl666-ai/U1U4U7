## 三、接下来: 测试 U4 功能

### 待测命令 (U1↔U4, 已实现)
- 0x10 传感器归零, 0x11 开始校准, 0x12 完成校准, 0x13 取消校准
- 0x14 读Flash参数, 0x15 保存参数, 0x16 恢复出厂, 0x20 AMS清零
- 0x50 版本, 0x18 设置报文周期, 0x30 报文
- ⚠️ 0x34 读全部ADC: 固件方**暂未实现** (QUERY_ADC target=4 依赖, 待固件支持)

### 测试方法
- **TEST_U4 (0x0113)**: 依次测 0x10→0x20 共 8 个命令, 每个发→等 ACK→PASS/FAIL, 最后上报 0x0014 ADC
  ```
  A5 5B 01 13 00 01 00 00 5B B5
  ```
  预期: 8 个命令 PASS + ADC 结果 + ACK 0x00 (全PASS) / 0x05 (有FAIL)
- **TEST_ALL (0x0115)**: U4 + U7 全测
  ```
  A5 5B 01 15 00 01 00 00 5B 3D
  ```
- **QUERY_U4_VER (0x000D)**: 版本查询
  ```
  A5 5B 00 0D 00 01 00 00 88 1C   → [00][01 03 01] 成功 或 [0C][00 FF FF] 失败
  ```
- **QUERY_FW_VER (0x000C)**: SPI Flash 版本 (标签, 与 U4 内部版本可能不同)
  ```
  A5 5B 00 0C 00 01 00 00 48 21
  ```

### 版本号差异说明
- QUERY_FW_VER 读 SPI Flash 头部 (上传 FW_START 填的版本, 是**标签**)
- QUERY_U4_VER 读 U4 固件内部版本 (编译在代码里, 是**真实版本**)
- 两者不一致 = 上传时 FW_START 版本填错了, 不是烧录问题

## 四、协议参考

### CRC 字节序
- **PC↔U1**: 高字节在前 (big-endian)
- **U1↔U4**: **低字节在前** (MODBUS RTU), 例 CRC 值 0x978D → 发 8D 97

### U1↔U4 串口
- 运行时: 115200 8N1
- ISP: 115200 8E1 (G0 bootloader 强制)

### PC→U1 帧格式
```
A5 5B | CMD(2B) | SEQ(2B) | LEN(2B) | DATA | CRC16(2B, 高字节在前)
```

### ⛔ 0x0011 测径精度校准 — 硬件前提未满足 (非固件问题)
- **现象**: 三位置全 FAIL, 实测 D≈900/906/900 (目标 1000/1500/2000)
- **根因**: 当前只有裸电机, **未装测量台** (无传动/磁条/被测件)
  - `position` (磁条位置) 全程 ~1345um 不动 → 电机空转没带动机构
  - `length` (实测直径) ~900um 不变 → U4 传感器前无被测物 (基线值)
- **报文证据**: USB-TTL 监听 U4 PA2 确认 0x10 ACK 正常、0x30 报文流正常
- **结论**: 协议层 100% 通, 需装好测量台 (电机→传动→磁条+被测件) 后重测

## 八、ADC 一致性校验改动 (2026-08-14)

**问题**: U4 固件未实现 0x34, 一致性校验取不到 U4 ADC (全 0 被跳过)
**方案**: 改从 0x30 报文流取 U4 数据 (`adc_consistency.c`)
- U4 CH1 = `vo1`, CH2 = `vo2`, CH3 = `ams_adc` (status=1)
- U4 CH4 不在报文流 → status=0, 待治具完成后固件方补
- 删除原「等 U4」阶段 (phase 1), 直接取最新报文 → 等 U7 → 比对
- 命令: `A5 5B 00 20 00 01 00 02 00 14 6B 54` (全芯片, 阈值20)
- 回 64B: [0..15]U1 [16..31]U4 [32..47]U7 [48..63]判定区
