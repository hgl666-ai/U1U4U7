# U1/U4/U7 治具系统项目总结

## 一、项目背景

**系统拓扑：**

```
PC ──[USB CDC]── U1(治具) ──[USART1]── U7(电机板)
                 U1(治具) ──[USART2]── U4(待测板)
```

| 芯片 | 型号 | 角色 |
|------|------|------|
| U1 | STM32F103C6 | 测试治具主板：接收 PC 命令/固件、控制测试流程、烧录 U4、与 U7 交互 |
| U7 | STM32F103C6 | 电机控制板：驱动 TMC2209 步进电机、响应 U1 的 7 条协议命令、ADC 采样 |
| U4 | STM32F103 | 待测目标板（对方提供），U1 通过治具下压后接触进行烧录和测试 |

**数据流：**

```
PC 上传 U4 固件 → U1(SPI Flash) → 治具下压 → ISP 烧录 U4
PC 发测试命令 → U1 → U7(电机运动) / U4(校准+ADC)
U4 自发报文(50ms) → U1 解析存储
```

---

## 二、预期目标

1. PC 通过串口上传 U4 固件（Bootloader + App）到 U1，U1 存入 SPI Flash 双槽
2. 治具下压后 U1 通过 ISP 协议烧录 U4（先 Bootloader 后 App）
3. U1 通过协议命令控制 U7 电机运动和读取传感器
4. U1 ↔ U4 校准协议：传感器归零、开始/完成/取消校准、Flash 参数读写、偏移值设置、报文周期配置、AMS 清零
5. U4 自发报文（ccd_data_t）周期上报，U1 自动解析存储
6. 全流程自动化测试：TEST U4 → TEST U7 → TEST ALL

---

## 三、通信协议

### 帧格式

| 链路 | 格式 | CMD 宽度 | 帧头长度 |
|------|------|---------|---------|
| PC ↔ U1 | `A5 5B \| CMD(2B) \| SEQ(2B) \| LEN(2B) \| DATA(*) \| CRC16(2B)` | 2B | 8B |
| U1 ↔ U7 | `A5 5B \| CMD(1B) \| SEQ(2B) \| LEN(2B) \| DATA(*) \| CRC16(2B)` | 1B | 7B |
| U1 ↔ U4 | `A5 5B \| CMD(1B) \| SEQ(2B) \| LEN(2B) \| DATA(*) \| CRC16(2B)` | 1B | 7B |

- 多字节字段均为大端序 (MSB first)
- CRC16: MODBUS-CRC (多项式 0x8005, 初值 0xFFFF)
- SEQ 从 1 递增, ACK 帧回显请求 SEQ, 自发帧 SEQ=0

## 六、U1 ↔ U7 联调结果

| 命令 | CMD | 结果 | 说明 |
|------|-----|------|------|
| PING | 0x21 | ✅ | 往返正常 |
| GetVersion | 0x22 | ✅ `V10` | v1.0 版本号正确 |
| MotorStep | 0x23 | 🔒 | 依赖 TIM3 PWM |
| MotorStop | 0x24 | 🔒 | 依赖 TIM3 |
| ReadInput | 0x25 | 🔜 | 待测 |
| SelfTest | 0x26 | 🔜 | 依赖 ADC |
| Reset | 0x27 | 🔜 | 待测 |

> **关键发现**：U7 心跳直接写 `USART1->DR` 会干扰 HAL `UART_SendArray` 发送的协议帧，导致 U1↔U7 联调全部失败。去掉心跳后恢复正常。USB TTL 的 TX 线接在总线上也会导致冲突，必须悬空。

## 八、当前阻塞项

| 问题 | 影响 | 根因分析 |
|------|------|---------|
| **U7 TIM3 初始化硬错** | 电机 STEP 脉冲无法产生、MotorStep/MotorStop 命令不可用 | `MX_TIM3_Init` 中 `HAL_TIM_PWM_Init` 或 `__HAL_AFIO_REMAP_TIM3_PARTIAL` 触发 `Error_Handler`。偶发正常（重烧后通过），需调试器定位 |
| **U7 TMC2209 读回失败** | 无法验证寄存器配置是否真正写入 TMC2209 | 软件 UART 发成功（`.AC`），但 BSP_TMC_ReadReg 收不到响应，已试 PA6/PA7 互换均返回 `1`。需示波器确认引脚波形 |
| **U1 ↔ U4 未量产验证** | 无法确认 ISP 烧录和校准协议 | U4 板未到位、治具未组装 |
| **6 条 IAP 命令 NIY** | U1/U7 自身固件无法在线升级 | 方案待定（串口 ISP 还是片内 IAP 库） |
