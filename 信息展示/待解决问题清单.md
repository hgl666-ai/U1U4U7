## ① ④ 测径精度 —— 板间灵敏度差 3.5 倍【2026-11-15 暂缓】

### 现象

同样命令走 2mm，两台 DUT 的读数变化差 3.5 倍：

| | DUT1（后退 4 次 = 2mm）| DUT2（前进 4 次 = 2mm）|
|---|---|---|
| `position` | 582 → 625（**+43**）| 517 → 381（**−136**）|
| `length` | 1168 → 1125（−43）| 1331 → 1467（+136）|
| `vo1` | 1682 → 1480（**−202**）| 1919 → 2627（**+708**）|
| `length+position` | 1750 → 1750 | 1848 → 1848 |
| **vo1 灵敏度** | **101 计数/mm** | **354 计数/mm** |

### 已排除

| 项 | 结论 |
|---|---|
| 电机 / 丝杆 / 步数标定 | ✅ 正常 —— 实测 **4 次点动 = 2mm**，与固件 1600 步/mm 完全吻合 |
| 夹具重复性 | ✅ 正常 —— 前进 5 次再后退 5 次，能精确回到起点 |
| 运动方向 | ✅ 正确 —— 前进 position 减小，后退增大 |
| 电机电流 | ✅ 0.275A 下"能动且不发热"，不需调整 |

### 结论

- **夹具侧没问题，问题在 DUT 板间一致性。**
- `length + position` 在同一块板内**完全恒定** → `length` 是由 `position` 减出来的，
  **不是独立测量值**，两个字段只携带一份信息。
- ④ 现有判据 `|Dactual − N| ≤ 50µm` 是"绝对读数 vs 命令位置"，**必然失败**
  （板间差 3.5 倍，调不出一个能同时通过两块板的值）。

### 待决定的两条路

**路 A：逐板标定（正规做法，能做 ±50µm）**
每块 DUT 用夹具走一个已知距离（如 2mm），记录 `vo1` 变化量，算出该板灵敏度系数，
写入 U4 flash。之后 `length` 才是准的。
→ 需要 U4 固件支持标定流程（`0x11 开始校准` / `0x12 完成校准` 是否就是做这个？待确认）

**路 B：只做功能筛选（放宽判据）**
验证：方向正确、往返能回原点、变化量在合理区间（如 100~800 计数/2mm）。
能筛掉完全不响应/方向反了的坏板，但筛不出灵敏度偏差。

### 待确认

1. 两块板是同型号、同固件版本吗？
2. U4 的 `0x11/0x12` 校准到底在标什么？
3. 产线对直径精度的真实要求是多少？（决定走 A 还是 B）

## ② 烧录后复位只有约 50% 成功率【硬件问题，待加电阻】

### 现象

烧录完成后，U4 的应用"每隔一次才启动"（严格交替，约 50%）。

### 已定位的根因

用万用表实测 **U4 的 NRST 脚**：

```
正常运行 = 3.3V
发复位命令 → 3.3 → 0 → 2.3V   ← 停在这里！应用不跑
再发一次   → 2.3 → 0 → 3.3V   ← 应用正常
```

**2.3V 恰好等于 STM32 的复位阈值（0.7 × 3.3V = 2.31V）**，
芯片卡在"复位/释放"的判定线上，于是每次复位结果翻转。

### 已排除

| 假设 | 结论 |
|---|---|
| BOOT0 电平不对 | ❌ 实测 ≈0V，正常 |
| NRST 没接线 | ❌ 已接 |
| PB15 被 SPI 复用 | ❌ flash 走 SPI1（PA5/6/7），PB15 是空的 |
| 复位脉宽不够 | ❌ 10ms → 50ms → 2s 都试过，无改善 |
| 双复位 | ❌ **更差**（偶数次 = 翻回原状态，见下） |

### 关键规律：复位是**奇偶翻转**

`0x0028` 连发实测：好→坏→好→坏→好→坏→好（严格交替）。
所以：**奇数次复位 = 翻转，偶数次 = 翻回原状态。**
烧完时板子停在 bootloader，打 2 次复位等于没复位 → 这就是"双复位更差"的原因。

### 根治办法（硬件，一个电阻）

**在 U4 的 NRST 与 3.3V 之间加 10k 上拉电阻。**
加上后静息电平稳在 3.3V，问题彻底消失，软件不用再改。

（备选：减小 PB15→NRST 的串阻，或去掉 NRST 上的对地下拉/减小对地电容。）

### 软件侧的临时手段

调试命令 `0x0028 复位U4`：带 3 次重试（50/500/500ms），烧录后灯不闪时可手动发一次抢状态。
