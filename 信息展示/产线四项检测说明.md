# 产线四项检测说明（烧录 / ADC一致性 / ADC极值 / 测径精度）

> 日期: 2026-11-13
> 适用: U1(STM32F103C6 治具主控) + U7(电机板) + U4(STM32G031 被测板)
> 依据: **以当前代码为准**（已含 2026-11-13 换 20mm 丝杠电机后的新参数）
> 用途: 上位机联调 / 产线作业 / 验收判定

---

## 〇、共同前提

| 项 | 要求 |
|---|---|
| U4 必须在线 | 否则 0x000D 查版本失败，后三项都做不了 |
| 电机行程 | 20mm 固定轴丝杠电机，**导程 1mm，有效行程 12.7mm** |
| 步数换算 | **3200 步/mm**（1.8° 电机 200 步/圈 × 16 细分） |
| 电机电流 | irun=17 ≈0.55A（0.6A 额定 92%），vsense=1 低量程 |
| 回零 | 最长 **28 s**（42000 步 @1500Hz）——上位机超时要设够 |
| 互斥 | `0x0010` / `0x0011` / `0x0013` 不能并发，并发时回 `0x01 BUSY` |

## 一、烧录检测 — `0x0112` PROGRAM

### 命令帧
```
A5 5B 01 12 <SEQ H/L> 00 00 <CRC H/L>
例(SEQ=1): A5 5B 01 12 00 01 00 00 9B 88
```

### 治具做什么
1. 校验 SPI Flash 双槽：size 有效（1~65528）+ 完整标志 `0xA5` + Bootloader ≤ 分配区
2. 串口切 **115200 8E1**（U4 bootloader 要求）
3. `ISP_Connect`：BOOT0 拉高 → NRST 脉冲 → 发 `0x7F` 等 `0x79`
4. 读 U4 UID（`0x1FFF7590`，12B）→ 主动上传 `0x0024` SN 帧
5. 全片擦除 `0x44` + `FF FF 00`
6. 写 Bootloader（14560B → `0x08000000`）
7. 写 App（34404B → `0x08005000`）
8. `ISP_Go(0x08000000)` → 拉低 BOOT0 → 复位 → 串口切回 **8N1**

### 判定
**ACK = `0x00` 且耗时 ≈ 6.04 s**

| ACK | 含义 |
|---|---|
| `00` | OK |
| `02` | ERR_SIZE（Bootloader bin 超过分配区 / 大小异常）|
| `04` | ERR_PROG（ISP 握手/擦除/写 失败）|
| `06` | ERR_NO_FW（槽内无固件）|
| `07` | ERR_INCOMPLETE（完整标志缺失）|

### ⚠️ 注意
- **不要用 `0x000D` 判断烧录成败**：该查询走 U4 会话解析器，会被 0x30 报文流遮蔽而产生假失败。判烧录只看 `0x0112` 的 ACK + 耗时。
- 烧录失败后 U1 会把 USART2 停在 8E1 且 BOOT0 留高，**需重启 U1 才恢复**。

## 二、ADC 一致性检测 — `0x0020` (LEN=2 全芯片模式)

### 命令帧
```
A5 5B 00 20 <SEQ H/L> 00 02 00 <Threshold> <CRC H/L>
例(SEQ=2, 阈值20=0x14): A5 5B 00 20 00 02 00 02 00 14 6B 10
例(SEQ=2, 阈值50=0x32): A5 5B 00 20 00 02 00 02 00 32 B1 91
```
`DATA[0]=0x00` 表示全芯片模式，`DATA[1]=Threshold`（LSB，默认建议 20）

### 治具做什么
1. 读 **U1 本地** 4 路 ADC（VO1/VO2/AMS5600/VDD，各 4 次平均）
2. 从 **U4 报文流** 取 `vo1 / vo2 / ams_adc`（U4 固件未实现 0x34，只能这样取）
3. 向 **U7** 发 `0x28` 要 4 路 ADC（超时 5 s）
4. 逐通道算 `MaxDiff = max(raw) − min(raw)`（只统计 status=1 的芯片）

### 判定
**每个通道独立判定**：
```
pass = (有效芯片数 ≥ 2) && (MaxDiff ≤ Threshold)
```

### ACK 64 字节解析
| 字节 | 内容 |
|---|---|
| `[0..15]`  | U1：4 通道 × `[ch_id][ADC BE 2B][status]` |
| `[16..31]` | U4：同上 |
| `[32..47]` | U7：同上 |
| `[48..63]` | **判定区**：4 通道 × `[ch_id][MaxDiff BE 2B][pass 1/0]` |

### ⚠️ 注意
- **U4 的 CH4(VDD) 不在报文流** → status=0 → 通道 4 只比 U1 vs U7
- U4 数据取的是"**最新一帧报文**"，**没有新鲜度校验**：U4 掉线时可能用旧值参与比对
- U7 超时 → 该段全 0、判定 FAIL（ACK 慢回 = U7 链路有问题）
- **CH3 标度补偿（2026-11-13 新增）**：实测 U4 的 `ams_adc` 只有 U1/U7 同测点的
  **0.849~0.860 倍**（4 块板实测，离散 ±0.7%），疑为 U4 PA6 处有分压。
  固件在**填入缓冲区时**就把 U4 的 CH3 乘以 **117/100** 归一化，否则 CH3 恒偏 ≈290 LSB 必 FAIL。
  - ✅ **ACK 里 U4 段 CH3 返回的就是补偿后的值**（与 U1/U7 同标度，可直接横向对照）
  - U4 的**原始值**仍可从 0x30 报文流的 `ams_adc` 字段读到（报文流不做补偿）
  - 对应宏：`app.h` 的 `ADC_CONSIST_U4_AMS_NUM/DEN`
  - 若日后查清并修正了硬件分压，把分子改回 `100` 即关闭补偿
  - 补偿后 4 块实测板 CH3 的 MaxDiff：10 / 9 / 14 / 14（阈值 20 全部通过）

## 三、ADC 极值检测 — `0x0010`

### 命令帧
```
A5 5B 00 10 <SEQ H/L> 00 00 <CRC H/L>
例(SEQ=3): A5 5B 00 10 00 03 00 00 4A 51
```

### 治具做什么
```
① U7 回零 (motor_pos=0)
② U1 发 U4 开始校准 (0x11)                  ← 校准窗口起点
③ 电机 CCW 移 3mm (9600 步) → 等待
④ 电机 CW  移 3mm (9600 步) 回零点 → 等待
⑤ U1 发 U4 完成校准 (0x12)                  ← 校准窗口终点
⑥ 延迟 200 ms
⑦ 读 U4 报文流 0x30 的 min_vo1/max_vo1/min_vo2/max_vo2
⑧ 阈值判定 → 回 9B ACK
```

### 判定（逐通道，三条**全部满足**才 PASS）
| 条件 | 阈值 | 含义 |
|---|---|---|
| `MAX − MIN ≤ 2000` | 2000 LSB | 摆幅不能过大（过大视为异常）|
| `MAX ≤ 4000` | 4000 | 不能饱和 |
| `MIN ≥ 50` | 50 | 不能贴底 |

**CH1、CH2 任一通道 FAIL → 整体 FAIL。**

### ACK 9 字节
| 字节 | 内容 |
|---|---|
| `[0]` | Status：`0x00` OK / `0x05` ERR_TEST |
| `[1..2]` | Max1 (BE) |
| `[3..4]` | Min1 (BE) |
| `[5..6]` | Max2 (BE) |
| `[7..8]` | Min2 (BE) |

失败时**仍带回 4 个极值**，可用于诊断：
- 全 `0` → U4 没填充极值字段（固件问题）
- 有值但超阈 → 真的测到异常（机构/传感器）

### ⚠️ 关键依赖
**U4 固件必须在 `0x11 → 0x12` 校准窗口内填充报文流的 `min_vo1/max_vo1/min_vo2/max_vo2`。**
若 U4 不填充（全 0）→ `MIN=0 < 50` → **必判 FAIL**（安全兜底）。
> 详见《窗口依赖分析》一节——当前窗口其实很宽松，真正的风险是"U4 填不填"。

## 四、测径精度检测 — `0x0011`

### 命令帧
```
A5 5B 00 11 <SEQ H/L> 00 00 <CRC H/L>
例(SEQ=4): A5 5B 00 11 00 04 00 00 4B DD
```

### 治具做什么
```
① 电机回零 (U7 0x29)
② U4 传感器归零 (0x10)
③ U4 设置偏移值为 0 (0x17，使 length = raw_length)
④ CCW 增量移动 1.0mm (3200 步) → 动态等到位 → 100ms 稳定 → 等新报文读 length = Dactual
⑤ CCW 增量移动 1.5mm (增量 +1600 步) → 同上
⑥ CCW 增量移动 2.0mm (增量 +1600 步) → 同上
⑦ 汇总 25B ACK
```

### 判定
**三个位置全部满足 `|Dactual − N| ≤ 50 µm`**（N = 1000 / 1500 / 2000 µm）

### ACK 25 字节
| 字节 | 内容 |
|---|---|
| `[0]` | 总判定：`1` = 全部 PASS / `0` = 存在 FAIL |
| `[1..8]` | 位置 1：`[编号][N BE 2B][Dactual BE 2B][Error BE 2B][判定]` |
| `[9..16]` | 位置 2：同上 |
| `[17..24]` | 位置 3：同上 |

### ⚠️ 关键依赖
**测量台必须装好**。未装测量台时 `Dactual` 恒定 ≈900µm（传感器前无被测件）→ 三个位置全 FAIL。这不是固件问题。

## 五、命令帧汇总

| 用途 | 完整帧（SEQ 可自增，需重算 CRC）|
|---|---|
| 烧录检测 | `A5 5B 01 12 00 01 00 00 9B 88` |
| ADC 一致性（阈值 20）| `A5 5B 00 20 00 02 00 02 00 14 6B 10` |
| ADC 一致性（阈值 50）| `A5 5B 00 20 00 02 00 02 00 32 B1 91` |
| ADC 极值 | `A5 5B 00 10 00 03 00 00 4A 51` |
| 测径精度 | `A5 5B 00 11 00 04 00 00 4B DD` |
| 辅助：查 U4 版本 | `A5 5B 00 0D 00 05 00 00 49 5D` |
| 辅助：查 U1 本地 ADC | `A5 5B 00 20 00 06 00 01 01 90 4E` |

> 帧格式：`A5 5B | CMD(2B) | SEQ(2B) | LEN(2B) | DATA | CRC16(2B, 高字节在前)`
> CRC16 = MODBUS（poly 0xA001 反射，初值 0xFFFF），范围 A5..DATA 末字节

## 六、耗时汇总（上位机超时务必设够）

| 检测 | 典型 | 最长 | 说明 |
|---|---|---|---|
| 烧录检测 | 6.04 s | 6.1 s | 约 192 页 ISP 写 |
| ADC 一致性 | ~0.3 s | 5.3 s | U7 超时 5 s |
| ADC 极值 | ~20 s | **~49 s** | 含回零 28 s + 两段各 10.1 s |
| 测径精度 | ~8 s | **~36 s** | 含回零 28 s + 三段等待 |

**为什么这么长**：
- 回零最长 28 s（42000 步 @1500 Hz，新丝杆电机 12.7mm 满行程）
- 电机等待按 **1 ms/步** 计算（实际约 0.5 ms/步，留了 2 倍余量）

> 旧版固件回零只要 6.4 s，**不要沿用旧超时值**，否则会把正常流程误判为超时。

## 七、窗口依赖分析（`0x0010` 的 U4 min/max）

### 当前窗口有多"死"
窗口 = `U4 收到 0x11` 到 `U4 收到 0x12` 之间。实际时长：

| 段 | U1 等待 | 电机实际 |
|---|---|---|
| 去程 9600 步 | 500 + 9600×1 = **10.1 s** | ≈5.8 s |
| 回程 9600 步 | **10.1 s** | ≈5.8 s |
| 合计窗口 | **≈20.4 s** | 电机只动 11.6 s |

→ **窗口并不紧，反而很宽松**（每段多等约 4.3 s）。

### 真正的影响
| 情况 | 结果 | 偏向 |
|---|---|---|
| 窗口够长（现状）| 正常 | — |
| 窗口偏短（电机没走完就发 0x12）| 采样范围变小 → MAX−MIN 变小 | **更容易 PASS** |
| 窗口偏长（多等）| 电机静止，极值不变 | 无影响 |
| **U4 不实现窗口**（自由累计）| 极值含历史 → MAX−MIN 可能变大 | **更容易 FAIL** |
| **U4 完全不填**（全 0）| MIN=0 < 50 | **必 FAIL** |

**结论：窗口松紧不是主要风险，"U4 到底填不填"才是。**

## 八、变更记录

### 2026-11-13（换 20mm 固定轴丝杠电机）
| 项 | 旧 | 新 |
|---|---|---|
| 位置换算基址 | 15500 µm/圈（旋转机构周长）| **1000 µm/圈（导程 1mm）** |
| 1mm 对应步数 | 206 步 | **3200 步** |
| ADC 极值 3mm 扫描 | 619 步 | **9600 步** |
| 测径 1/1.5/2mm | 206/310/413 步 | **3200/4800/6400 步** |
| 电机等待公式 | 2 ms/步 | **1 ms/步** |
| 回零步数上限 | 3200（1mm）| **42000（12.7mm 全行程）** |
| 回零速度 | 500 Hz | **1500 Hz** |
| 回零超时 | U7 8s / U1 8s | **U7 35s / U1 40s** |
| TMC 电流 | irun=24, vsense=0（≈1.38A）| **irun=17, vsense=1（≈0.55A）** |
| 电机方向 | — | **MOTOR_DIR_INVERT=1**（取反，实测 0x0025=后退 0x0026=前进）|
| 新增命令 | — | **0x0025 后退 / 0x0026 前进（不回零点动，1600步=0.5mm）** |

### 已知遗留风险
1. `0x0010` 的极值完全依赖 U4 填充 min/max 字段（见第七节）
2. ADC 一致性无报文新鲜度校验（U4 掉线可能用旧值）
3. TMC 配置失败是静默的（无指示）
4. 烧录失败后需重启 U1 才能恢复 8N1 / BOOT0 低
