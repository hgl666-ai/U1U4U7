# 电机回零 + 定点移动 功能总结

> 日期：2026-08-22 | 状态：✅ 已实现并通过全部验收测试

---

## 一、功能概述

为 U1/U7 治具系统新增两个 PC 命令：

| 命令 | 功能 | 状态 |
|---|---|---|
| **0x0012 电机回零** | 电机低速正转（CW）找 IN1 限位零点，回零完成即建立绝对位置原点 | ✅ |
| **0x0013 定点移动序列** | 自动执行 回零 → 1mm → 1.5mm → 2mm 三段定点移动 | ✅ |

**架构原则**：电机实时控制（限位检测、加减速、计步）全部在 **U7 电机板**完成；U1 只做"命令转发 + 位置累计"，零新增文件。

---

## 二、命令定义

### PC ↔ U1（经理协议）

| 命令 | 帧格式 | 响应 |
|---|---|---|
| `0x0012` 回零 | `A5 5B 00 12 N N 00 00 CRC`（无数据） | 1B 状态：`0x00` OK / `0x01` BUSY / `0x0C` 超时 |
| `0x0013` 定点序列 | `A5 5B 00 13 N N 00 00 CRC`（无数据） | 1B 状态：`0x00` OK / `0x01` BUSY / `0x05` 流程失败 |

### U1 ↔ U7（板间协议）

| 命令 | 帧格式 | 响应 |
|---|---|---|
| `0x29` 回零 | `A5 5B 29 N N 00 00 CRC`（无数据） | 1B 状态：`0x00` OK / `0xFF` ERROR |

## 三、代码调用路径

### ① 0x0012 回零（PC → U1 → U7 → 电机）

```
PC 发 0x0012
 └→ U1 USB CDC 中断 → APP_Frame_Feed()          [app_frame.c 帧接收状态机]
     └→ APP_Run() 主循环 → Frame_Parse() CRC 校验 → APP_Dispatch()
         └→ case MGR_CMD_MOTOR_HOME(0x0012)      [app.c:580]
             ├─ busy 检查 (MotorSeq_IsBusy/deferred_cmd/app_state)
             ├─ U7_Home()                        [protocol_u7.c]
             │   └─ U7_SendCmd_Start(0x29, NULL, 0, 1, 8000ms), max_retry=1
             │       └─ U7_Proto_Run() 推进会话: SEND 帧 → USART1 → WAIT_RESP
             └─ 返回 PENDING → deferred_cmd = 0x0012 (非阻塞)
```

```
U7 收 0x29
 └→ USART1 收帧状态机 [protocol.c S_HDR0..S_CRC_H] → Dispatch()
     └→ case PROTO_CMD_HOME(0x29) → HandleHome()  [protocol.c:123]
         ├─ BSP_Motor_Home()                      [bsp_motor.c:196]
         │   └─ BSP_Motor_Move(CW, 3200步, 500Hz) → TIM3 PWM 启动
         │       (freq=500Hz==起步频率 → 无加减速, 全程低速直跑)
         ├─ 阻塞轮询 HomeDone/HomeFail (兜底 8s)
         └─ SendResponse(0x29, 0x00 OK / 0xFF ERROR)
```

```
U7 电机运动过程 (ISR 内)
 └→ HAL_TIM_PeriodElapsedCallback(TIM3) 每脉冲一次  [bsp_motor.c:257]
     ├─ motor_count++ (计步)
     ├─ 回零检测 (home_active):
     │   ├─ 前 8 步不检测 (启动保护, 电荷泵/电平稳定)
     │   └─ 每步读 IN1(PB9)/IN2(PB10):
     │       IN1 低电平连续 4 步 → home_done=1 (到零点) → motor_halt() 停 PWM
     │       IN2 低电平连续 4 步 → home_fail=1 (撞对侧) → motor_halt()
     ├─ 到位 (motor_count ≥ target) → home_fail=1 + motor_halt() (3200步无触发=超时)
     └─ 梯形加减速: ARR 域分档调速 (回零 500Hz 恒定, 无加减速)
```

```
U1 收结果 (deferred 完成)
 └→ APP_Run(): deferred_cmd == 0x0012 → U7_Home() 返回
     ├─ OK  → motor_pos = 0 (建立绝对原点) → APP_SendAck(0x0012, 0x00)
     └─ 失败 → APP_SendAck(0x0012, 0x0C)
```

### ② 0x0013 定点移动（状态机，U1 主循环推进）

```
PC 发 0x0013
 └→ APP_Dispatch() case MGR_CMD_MOTOR_SEQ(0x0013)  [app.c:598]
     └→ MotorSeq_Start() → seq_phase=1 (HOME)      [app.c:714]

APP_Run() 主循环每轮调 MotorSeq_Run()              [app.c:723]
 ├─ phase 1 HOME:  U7_Home() → OK → motor_pos=0 → phase 2
 ├─ phase 2 MOVE:  target = um×3200/15500           [MotorSeq_StepsFor]
 │                 delta  = target − motor_pos
 │                 U7_MotorStep(MOTOR_ID, U7_MOTOR_CCW, delta)  ← 方向 CCW!
 │                 (max_retry=1 禁重试, 防重复动作)
 │                 → 设 seq_deadline = 500ms + delta×2ms → phase 3
 ├─ phase 3 WAIT:  等 deadline 到 → motor_pos=target → seq_step++
 │                 seq_step<3 → phase 2 (下一段) | 否则 → phase 4
 └─ phase 4 DONE:  APP_SendAck(0x0013, 0x00 / 0x05)
```

U7 侧每段移动走 `HandleMotorStep` → `BSP_Motor_Move(CCW, delta, 2000Hz)` → ISR 到位 → 回 `0x00`（U1 收到后 `U7_MotorStep` 返回 OK）。

### 关键换算

```
steps = um × 3200 步/圈 ÷ 15500 um 周长  (与 0x0011 测径一致)
  1mm  = 206 步  (从零点增量移动)
  1.5mm = 310 步 (增量 +103)
  2mm  = 413 步  (增量 +103)
```

### 方向设计（2026-08-22 修正）

```
回零: CW 正转 → 顶到 IN1 限位端点停 (电机停在行程边界)
定点: CCW 反向 → 远离限位进入行程区 (必须与回零反向, 否则顶限位失步)
```

## 四、关键实现细节

| 环节 | 实现 |
|---|---|
| **限位检测** | ISR 每脉冲读 GPIO（~1µs），低电平触发（外部上拉 + 开关拉地），去抖连续 4 步确认 |
| **启动保护** | 前 8 步不检测（电荷泵建立 + 电平稳定），防启动毛刺误判 |
| **梯形加减速** | ARR 域线性分档（500Hz 起步 → 2000Hz 目标），三角退化防小步数高速急停；回零 500Hz 恒定 |
| **到位保持力矩** | 到位只停 PWM、保持 EN=0（TMC IHOLD≈0.35A 锁死防滑步）；`BSP_Motor_Stop()` 才脱机 |
| **HAL 状态还原** | ISR 直接寄存器停 PWM 后还原 `ChannelState[]`+`State`（HAL v1.10+ 通道级检查，防"第二段 START_IT FAIL"） |
| **会话隔离** | U1 侧 PING/MotorStep/Home 的 DONE 分支做 cmd 归属校验，防跨命令消费残留结果 |
| **命令禁重试** | MotorStep/MotorStop/Home 均 `max_retry=1`（电机命令非幂等，超时重试=重复动作） |
| **调试开关** | `U7_DEBUG`（命令诊断，`#if U7_DEBUG` 风格）、`U7_TMC_PRINT`（上电 TMC 打印，默认 0） |

## 五、调试历程（关键问题与根因）

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 回零"电机转一下就不动" | ISR 内调试打印阻塞 2.9ms > 2ms 脉冲周期 | 打印全部移出 ISR（主循环打印） |
| 2 | 回零"不动却成功" | 限位触发极性搞反（按"触发变高"写成 !=0） | 实测 `HOME done + 电机不转` → 改为**低电平触发 ==0** + GPIO PULLUP |
| 3 | 回零转满 1600 步不触发 | 方向反（零点在 CW 侧） | `MOTOR_HOME_DIR` CCW→**CW** |
| 4 | "电机只走 1 步就停"（间歇） | 限位引脚 NOPULL 悬空读值漂移误判 | GPIO 改上拉 + 启动保护 8 步 + 去抖 4 步 |
| 5 | "5ms 假成功" | U1 跨命令消费 PING 残留的 DONE_OK | U7 会话 DONE 分支加 **cmd 归属校验** |
| 6 | 重启后首命令偶发失败 | U7 上电 TMC 调试打印灌烂 U1 RX DMA | `U7_TMC_PRINT` 默认 0（U7 上电零输出）+ U1 上电延迟 2s |
| 7 | 定点移动"只走两段" | 定点方向误用 CW，回零后继续顶限位失步 | MOVE 方向 CW→**CCW**（用户发现，判断正确） |

## 七、注意事项

1. **IN1/IN2 当前未外接限位开关**（测试用杜邦线短接 PB9-GND 模拟触发）。正式使用需接常开开关：一端接 PB9/PB10，一端接 GND（未触发悬空=高，压下接地=低），代码无需再改。
2. **回零期间 U7 阻塞 ≤6.4s**，期间不响应其他 U7 命令；U1 的 U7_Home 超时 8s 覆盖。
3. **电机到位保持力矩**（ihold=8 ≈0.35A，功耗 ~7W）：长时间不用可发 `0x24 MOTOR_STOP` 脱机省电。
4. **调试开关**：`U7_DEBUG`（bsp_tmc2209.h:42，1=开）控制 HOME/STEP 命令诊断；`U7_TMC_PRINT` 控制上电 TMC 打印（默认关，开启会污染 U1 DMA，勿在生产开）。
5. **U1 Flash 已满**（~32KB 极限）：新增功能需先压缩存量（TEST 标题已压缩，[WARN] 打印已删）。

## 八、涉及文件清单

**U7（执行者，4 文件）**
- `bsp_motor.h`：回零参数宏（方向/速度/最大步数/启动保护/去抖）
- `bsp_motor.c`：`BSP_Motor_Home/HomeDone/HomeFail`、`motor_halt`、ISR 限位检测
- `protocol.h/.c`：`PROTO_CMD_HOME 0x29` + `HandleHome`
- `gpio.c`：PB9/PB10 输入上拉

**U1（转发+状态机，4 文件）**
- `app.h`：`MGR_CMD_MOTOR_HOME 0x0012` / `MGR_CMD_MOTOR_SEQ 0x0013`
- `app.c`：`motor_pos` 位置累计、0x0012 deferred、`MotorSeq_Start/Run` 状态机
- `protocol_u7.h/.c`：`U7_CMD_HOME 0x29` + `U7_Home()`
